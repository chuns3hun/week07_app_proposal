# MIDTERM_PLAN — 1~7주차 학습 점검과 보완 계획

## 1. 시험 정보 (과제 안내문 기준)
- 범위: 1~7주차
- 형식: 객관식 25문항 + 주관식 5문항, 총 30문항·30점
- 방향: 정의 암기 + 화면·코드·기획 상황에 적용
- 시험일: 8주차 수업 (정확한 날짜·시각은 공지로 재확인)

## 2. 주차별 학습 점검
근거는 본인 GitHub 실습 저장소, 6주차 실습 안내문, 7주차 과제·실습 안내문이다. 6주차 실습 저장소(week6_notice)는 공개 저장소 목록에서 확인하지 못했다.

## 3. 복습 질문 (실제 시험 문제 아님)
1. `flutter doctor`와 `flutter devices`는 각각 무엇을 확인하는가?
2. AC를 Given-When-Then으로 쓰면 무엇이 좋아지는가?
3. 입력값을 `trim()` 하지 않으면 어떤 입력이 통과되는가?
4. Column 안에 ListView를 넣을 때 Expanded가 없으면 어떤 문제가 생기는가?
5. `setState` 없이 리스트에 값을 추가하면 화면은 어떻게 되는가?
6. 완료 개수를 별도 변수로 저장하면 어떤 버그가 생길 수 있는가?
7. MVP의 "보류"와 "제외"는 어떻게 다른가?
8. 외부 요청이 핵심인 앱의 AC에 추가해야 하는 조건 두 가지는?
9. `flutter analyze`의 No issues found가 확인해 주지 않는 것은?
10. AI 응답 코드를 실행하지 않았을 때 문서에 어떻게 기록해야 하는가?
11. 함수에 `async`를 붙이면 계산이 다른 isolate로 옮겨 가는가?
12. 1초 응답을 기다리는 것과 큰 JSON을 계산하는 것은 어떻게 다른가?
13. 요청 중 버튼을 잠그지 않으면 어떤 문제가 생기는가? 어떻게 확인하는가?
14. `await` 뒤에 `mounted`를 검사하는 이유는?
15. broadcast Stream에서 구독 전에 보낸 값은 왜 받지 못하는가?
16. 실패 후 재시도할 때 이전 오류 문구를 지워야 하는 이유는?

## 5. 위험과 대응
- 6주차 비동기 개념(async·isolate·Stream)이 가장 헷갈리기 쉬움 → 계획 1번을 가장 먼저 한다.
- 다른 과목 시험·발표와 일정이 겹침 → 전날에는 새 내용 대신 오답 재풀이만 한다.
- 공부 시간만 채우고 실력을 확인하지 않음 → 2절의 ○△✕는 복습 질문을 실제로 풀어 본 결과로만 고친다.
